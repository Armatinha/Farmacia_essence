# Product Images Directory

Drop your product photos in this folder.
Supported formats: PNG, JPG, JPEG, WEBP.

Example:
- If you save a photo as: `public/products/retatrutide-box.png`
- In the dashboard or CSV, set the Image URL to: `/products/retatrutide-box.png`

Pre-bundled photos available in the system:
- `/essence-vials.png` (Lyophilized vials with silver flip-off caps)
- `/essence-pen-box.png` (Pharmaceutical box and precision injector pen)
- `/essence-seals.jpg` (Official holographic tamper-evident scratch seals)
